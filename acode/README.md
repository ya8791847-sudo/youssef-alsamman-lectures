# تشغيل لقطة AI على تطبيق Acode (أندرويد) 📱

الملفات اللي في الفولدر ده **ملف HTML واحد مستقل** فيه الاستوديو كامل (React + كل الكود + كل التنسيقات جوّاه)،
يعني **مش محتاج npm ولا إنترنت ولا أي build على الموبايل** — تفتحه وبيشتغل.

| الملف | الحجم | لإيه |
| --- | --- | --- |
| `index.html` | ~460 KB | **النسخة الأساسية** — مضغوطة (minified)، دي اللي تفتحها/تشاركها. |
| `dev.html` | ~765 KB | نسخة غير مضغوطة (أسماء الدوال واضحة) للفحص والتعلّم — أبطأ في الفتح جوه محرر Acode. |

---

## الطريقة ١ — الأسرع: تنزيل ملف واحد على الموبايل

1. نزّل ملف `index.html` على الموبايل (من مستودع GitHub: زر **Raw** ثم حفظ، أو أي مشروع نسخ محلي).
2. افتح تطبيق **Acode** → افتح الملف من قائمة الملفات (`index.html`).
3. من قائمة Acode اختار **Open in browser** (أو «تشغيل / Run» أو **Preview** حسب النسخة والـ plugins).
   - لو معندكش plugin للمعاينة: من مدير الملفات اختار الملف → **فتح باستخدام → Chrome**.
4. الاستوديو بيفتح على الداشبورد بالعربي. اضغط **«مشروع تجريبي»** لتشوف كل حاجة شغالة فورًا.

> نصيحة: انسخ الملف لمجلد ثابت مثل `/storage/emulated/0/Laqta/index.html` عشان تحفظه بسهولة.

## الطريقة ٢ — نسخة كاملة من المشروع جوه Acode (للتعديل)

1. حمّل المشروع كامل (ZIP من GitHub) وفكّه في مجلد على الموبايل.
2. في Acode افتح `acode/index.html` للأستخدام، أو `src/...` لو عايز تقرأ/تعدّل الكود المصدري.
3. لو عدّلت أي حاجة في `src/`، لازم تعيد بناء ملف الموبايل بأمر واحد على كمبيوتر (أو Termux):

```bash
npm install
npm run build:acode      # يطلع acode/index.html و acode/dev.html
```

## الطريقة ٣ — تشغيل سيرفر محلي (لو عندك Termux)

الأفضل لو عايز **المايك والشاشة الكاملة** (الاستيراد/التسجيل بيشتغلوا أحسن على `http://`):

```bash
npm install
npm run dev -- --host          # افتح من الموبايل: http://<IP-الكمبيوتر>:5173
# أو سيرفر HTML ثابت بسيط:
npx serve .                     # أو: python3 -m http.server 8080
```

## إيه اللي بيشتغل في معاينة Acode وإيه اللي لأ

| الميزة | معاينة Acode (`file://`) | Chrome على الأندرويد |
| --- | --- | --- |
| الداشبورد + المحرر + الخط الزمني | ✅ | ✅ |
| كل أدوات الذكاء الاصطناعي (٤/١٤ بدون تحليل صوتي) | ✅ | ✅ |
| القص/السحب/التقطيع باللمس + تغيير المقاس | ✅ | ✅ |
| استيراد ملفات من الموبايل | ⚠️ بيعتمد على الـ WebView (لو الزر مافتحش مدير الملفات، استخدم Chrome) | ✅ |
| تصدير WebM/WAV/PNG/SRT | ⚠️ WebView ساعات بيتجاهل تنزيل `blob:` — فيه زرار **«فتح الملف المصدَّر»** بديل | ✅ |
| حفظ المشروع تلقائيًا (IndexedDB) | ✅ في الغالب (ليه fallback للذاكرة) | ✅ |
| المايك (تعليق صوتي / تفريغ الكلام) | ❌ `file://` مش بيسمح بالمايك | ❌ كذلك — محتاج `http://localhost` أو HTTPS |
| الشاشة في الشاشة / الرندر بالوقت الحقيقي | ✅ | ✅ |

**الخلاصة:** Acode تمام للتعديل والتجربة السريعة والتشغيل، و**Chrome** أفضل للمايك والتصدير.

## نصايح لشاشة الموبايل

- الأدوات بتظهر في **تبويبات** فوق الشاشة الصغيرة: `الوسائط` و `أدوات AI` و `المؤثرات` (يمين) — وفي الآخر زرار **«المعاينة»** يرجّعك للفيديو.
- للتكبير على الخط الزمني: زرار `+` في شريط الأدوات، أو **Ctrl + عجلة الماوس**.
- امسك طرف الكليب بصباعك لقصّه (المقابض عريضة ١٨px مخصوص للمس).
- تشغيل/إيقاف: زرار `▶` في الشريط العلوي أو المسافة (Space) لو عندك كيبورد.

## لو حصلت مشكلة

| المشكلة | الحل |
| --- | --- |
| الصفحة بيضاء | تأكد إنك فتحت `acode/index.html` (الملف المستقل) مش `dist/index.html` — التاني محتاج سيرفر. |
| زر الاستيراد مافتحش ملفات | WebView ممنوع منه file picker → افتح الصفحة في **Chrome**. |
| التحميل مافتحش | اضغط **«فتح الملف المصدَّر»** في لوحة التصدير، أو افتح في Chrome. |
| الكابشن المباشر مش شغال | طبيعي على `file://` — استخدم Chrome أو اكتب نص السكربت وخلّيه يتوزّع زمنيًا. |
| بطء في الفتح على موبايل قديم | استخدم Chrome، وصغّر مقاس المعاينة من الإعدادات، واقفل مسار الصوت الزيادة. |
