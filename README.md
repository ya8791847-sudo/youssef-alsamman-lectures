# لقطة AI — استوديو المونتاج بالذكاء الاصطناعي 🎬

**Laqta AI Studio** — استوديو مونتاج كامل يعمل داخل المتصفح، بدون سيرفر وبدون رفع أي ملف.
كل أدوات «الذكاء الاصطناعي» (كشف الصمت، تقسيم المشاهد، الإيقاع، القص الذكي للريلز، تحسين الألوان،
الكابشن، الهايلايت، تنقية الصوت، إزالة الخلفية الخضراء، كاتب العناوين) تعمل محليًا على جهازك.

واجهة عربية (RTL) بالكامل مع زر تبديل للإنجليزية.

## المزايا

**محرر خط زمني كامل**

- مسارات متعددة (فيديو / طبقات عليا / نصوص / صوت) مع كتم، عزل، إخفاء، قفل، وتحكم في مستوى كل مسار.
- سحب وإفلات المقاطع، قص من الطرفين، تقطيع عند المؤشر، حذف بإغلاق الفراغ، تكرار، التصاق ذكي (Snap).
- علامات (Markers) على الخط الزمني + علامات الإيقاع المكتشفة تلقائيًا.
- أشكال موجية حقيقية لمقاطع الصوت وصور مصغرة لمقاطع الفيديو.
- ٤٠ خطوة تراجع/إعادة (Undo/Redo) مع **اسم الإجراء** (تراجع عن: قص الطرف…) وحفظ تلقائي في IndexedDB.
- الواجهة بتفتح زي ما سِبتها: التكبير، التصاق، التمرير التلقائي، والتبويبات المفتوحة بتتحفظ.

**تكوين الفيديو (Canvas Compositing)**

- ١٦ فلتر لوني جاهز + تحكم يدوي كامل (سطوع، تباين، تشبع، حرارة، تدرّج، سيبيا، ضبابية، حدة، تظليل، حبيبة، توهج).
- ١٥ انتقالًا (تلاشي، ضبابي، انزلاق، مسح، دائرة، وميض، دوران، خلل رقمي…) بمدة قابلة للتحكم.
- تحويلات: حجم، موضع، دوران، شفافية، ملاءمة (cover / contain / stretch).
- حركات Keyframes لأي خاصية (حجم، موضع، دوران، شفافية) + حركات جاهزة (كين برنز، بانش، اهتزاز، طفو، دوران).
- فلاتر لمشروع كامل: إطار سينمائي، خلفية مضببة، شريط تقدّم، علامة مائية، تظليل، حبيبة فيلم.

**النصوص والكابشن**

- ٨ أنماط نصوص جاهزة + تحكم كامل في الخط، الحجم، السماكة، اللون، الحدود، الظل، الخلفية، المحاذاة.
- ١٠ حركات نصية: تلاشي، صعود، Pop، آلة كاتبة، كلمة كلمة، نطة، دخول جانبي، نيون، كاريوكي.
- نظام كابشن كامل: إضافة/تعديل/حذف الأسطر، دمج المتقارب، تقسيم الطويل، إزاحة زمنية جماعية، استيراد وتصدير SRT/VTT، وحَرق الكابشن داخل الفيديو.

**تجربة الاستخدام**

- تلميح بداية على الخط الزمني الفاضي (استيراد / إضافة الكل / فتح الوسائط) يختفي بعد أول مقطع.
- تأكيد قبل حذف مشروع أو حذف كل المشاريع من الصفحة الرئيسية.
- زرار **مشاركة** لملف التصدير عبر قائمة مشاركة النظام (Web Share) على الموبايل.
- إمكانية وصول (a11y): نوافذ بحصر تركيز لوحة المفاتيح، إغلاق بـ Escape، تسميات لكل أزرار الأيقونات،
  وحلقة تركيز واضحة — وكل الحركة تُلغى تلقائيًا مع `prefers-reduced-motion`.
- تحسينات للموبايل/Acode: أهداف لمس أكبر، احترام مناطق الأمان (notch)، منع تكبير النقر المزدوج،
  وتقليل معدل تحديث مقياس الصوت وقت الخمول لتوفير البطارية.

**الصوت**

- مستويات لكل مقطع ومسار، توزيع (Pan)، تلاشي دخول/خروج، كتم عام، ومقياس مستوى حقيقي.
- ١١ نمط معالجة صوتية (ستوديو، بودكاست، راديو، صوت عميق، مكالمة تليفون، قاعة، روبوت…).
- خفض الموسيقى تلقائيًا وقت الكلام (Ducking) + تطبيع الجهارة (Normalize).

## التشغيل السريع

```bash
# 1) تثبيت الاعتماديات
npm install

# 2) تشغيل نسخة التطوير (متاحة على الشبكة المحلية)
npm run dev          # → http://localhost:5173

# 3) بناء نسخة الإنتاج
npm run build        # → مجلد dist/ (استضافة ثابتة تكفي)
npm run preview      # معاينة نسخة الإنتاج

# 4) بناء ملف واحد مستقل للموبايل (Acode / أي WebView بدون إنترنت)
npm run build:acode   # → acode/index.html (457KB) + acode/dev.html

# 5) تشغيل كل الاختبارات (٣٠ منطق + ١٨ تكامل DOM + ١٢ محاكاة WebView)
npm test
```

> الأفضل استخدام **Chrome** أو **Edge** — لأن التصدير يعتمد على `MediaRecorder` والتفريغ الصوتي المباشر يعتمد على
> Web Speech API المتاح في Chrome.

## التشغيل على الموبايل (تطبيق Acode)

الاستوديو يشتغل جوه **Acode** على الأندرويد من غير npm ولا إنترنت، بفضل ملف واحد مستقل فيه كل الكود:

```bash
npm run build:acode        # يطلع: acode/index.html  و  acode/dev.html
```

1. انسخ `acode/index.html` على الموبايل (أو نزّله من GitHub → زر **Raw**).
2. افتح الملف من جوه **Acode** ← **Open in browser / Preview**.
3. اختار **«مشروع تجريبي»** وهتلاقي كل حاجة شغالة فورًا.

| الحالة | المعلومة |
| --- | --- |
| الداشبورد، المحرر، الخط الزمني، كل الأدوات | ✅ شغالة بالكامل (بدون إنترنت) |
| السحب/القص باللمس | ✅ مقابض أوسع (١٨px) + دعم `pointercancel` + منع تحديد النص |
| استيراد الملفات من الموبايل | ⚠️ WebView ممكن يمنع فتح مدير الملفات → افتح الصفحة في Chrome |
| التصدير (WebM/WAV/PNG/SRT) | ⚠️ بعض الـ WebViews بتتجاهل تنزيل `blob:` → فيه زرار **«فتح الملف المصدَّر»** |
| حفظ المشروع تلقائيًا | ✅ IndexedDB مع بديل آمن لو الذاكرة مقفولة |
| المايك (تعليق صوتي/تفريغ) | ❌ `file://` مش مسموح له بالمايك — يحتاج Chrome + `http://localhost` أو HTTPS |

تفاصيل أوفى ونصايح الأخطاء الشائعة في [`acode/README.md`](acode/README.md).

## الأدوات الذكية (١٤ أداة)

| الأداة | ما تفعله | المدخلات |
| --- | --- | --- |
| ✂️ **حذف الصمت** | تكشف السكتات في الصوت وتقصّها وتعيد بناء المقطع (Jump cuts) | حساسية، أقل مدة سكتة، مساحة قبل/بعد الكلام |
| 🎞️ **تقسيم المشاهد** | تكشف تغيّر المشاهد بتقدير الفرق التاريخي (Histogram) وتقسّم الفيديو | حساسية |
| 🎵 **القص على الإيقاع** | كشف النبضات + تقدير الـ BPM ثم التقطيع والعلامات على الإيقاع | حساسية، تطبيق، كل كم نبضة |
| 📐 **القص الذكي للريلز** | تتبع الهدف (بشرة/حركة) وإطار ٩:١٦ مع Keyframes لمتابعة الهدف | المقاس، تطبيق على المشروع |
| 🎨 **تحسين الألوان** | قياس السطوع/التباين/الصبغة وتصحيح تلقائي احترافي لكل مقطع | شدة التصحيح |
| 💬 **الكابشن التلقائي** | توزيع النص على الكلام المكتشف، أو تفريغ مباشر من المايكروفون | النص، سرعة الكلام، النمط |
| ⚡ **هايلايت ذكي** | اختيار أقوى اللحظات (طاقة صوت + حدود مشاهد) وبناء ملخص | الطول، أقل مدة للمقطع |
| 🖼️ **صورة الغلاف** | ترتيب الإطارات واختيار الأفضل كغلاف + كارت عنوان اختياري | عنوان، إضافة كمقطع |
| 🎚️ **تنقية الصوت** | معالجة صوتية كاملة (EQ، ضاغط، إزالة نشاز، صوت مكالمة…) | النمط، الشدة |
| ✨ **مؤثرات تلقائية** | إضافة Punch/Zoom/Shake على اللحظات القوية تلقائيًا | الشدة، النمط |
| 🟩 **إزالة الخلفية** | كشف اللون السائد بالخلفية وعزله مع تنعيم الحواف وكبح الانعكاس اللوني | الشدة |
| ✍️ **كاتب العناوين** | توليد ٦ عناوين + وصف + هاشتاجات + فصول من نص الفيديو | النبرة (يوتيوب/تيك توك/تعليمي…) |
| 🎼 **توليد موسيقى** | تلحين موسيقى خلفية محليًا (١٦ أسلوب: حماسي، هادي، ملحمي، لو-فاي، تك، فانك) | النمط، المدة، المستوى |
| 🏷️ **كارت عنوان** | توليد صورة عنوان بتدرّج لوني وخطوط عربية وإضافتها للمشروع | العنوان، السطر الفرعي، النمط |

كل أداة تظهر نسبة تقدّمها وتُسجّل في «سجل التنفيذ»، وكل العمليات قابلة للتراجع.

## المساعد الذكي (Copilot)

اكتب طلبك بالعربي أو الإنجليزي وسيُحوّل إلى خطة تنفيذ (عدة خطوات معًا):

```
امسح الصمت وسرّع الكلام 1.2x
اعمل نسخة ريلز عمودية
ولّد كابشن: "أهلاً بيك في الدرس الجديد"
اعمل هايلايت ٣٠ ثانية
حط فلتر سينمائي وزوّد الموسيقى
شيل الخلفية الخضراء
تراجع
```

المساعد يفهم أيضًا أوامر مباشرة: سرّع/بطّيء، اقطع، احذف، ارفع/اخفض الصوت، كتم، علامة، أضف نص، تصدير، تراجع/إعادة.

## الاستيراد والتصدير

**استيراد:** فيديو (mp4/webm/mov/mkv)، صوت (mp3/wav/m4a/aac/ogg/opus/flac)، صور (png/jpg/webp/gif/avif)،
ملفات ترجمة SRT/VTT، وملف مشروع JSON. كل الملفات تبقى في جهازك (IndexedDB).

**تصدير:**

- 🎬 **فيديو WebM** (VP9/VP8 + Opus) بدقة تصل 1080p مع تحكم في الـ FPS ومعدل البت — التسجيل في الوقت الحقيقي باستخدام MediaRecorder.
- 🎵 **صوت WAV** (ميكساج كامل بدون تشغيل — أسرع بكثير).
- 🖼️ **صورة PNG** للإطار الحالي بالدقة الكاملة.
- 💬 **SRT / VTT** للترجمة.
- 🗂️ **ملف المشروع JSON** لإعادة الفتح على أي جهاز.

## الخصوصية

- لا يوجد أي سيرفر أو API خارجي: كل التحليل والتكوين والتوليد يحدث داخل المتصفح.
- الفيديوهات والصور المولَّدة تُخزَّن في **IndexedDB** على جهازك فقط.
- لا يتم إرسال أي بيانات لأي طرف ثالث، ولا يوجد تتبع أو تحليلات.

```
src/
├── engine/
│   ├── player.js      محرك التشغيل: تجمّع عناصر الوسائط + ساعة صوتية + مزامنة
│   ├── renderer.js    تكوين الإطار: طبقات، فلاتر، كروما، انتقالات، نصوص، كابشن
│   ├── audio.js       مخطط Web Audio: معالجة صوتية، تحليل، توليد موسيقى، WAV
│   ├── analysis.js    تحليل الصورة: مشاهد، تتبع الهدف، أفضل إطار، تحسين الألوان
│   ├── exporter.js    التصدير: فيديو WebM، WAV، PNG، SRT/VTT، JSON
│   ├── presets.js     الفلاتر والانتقالات وأنماط النص والصوت والموسيقى
│   └── ai/

│       ├── copilot.js تحويل اللغة الطبيعية (عربي/إنجليزي) إلى خطة تنفيذ
│       └── writer.js  توليد العناوين والوصف والهاشتاجات
├── store/
│   ├── store.js       مخزن حالة خارجي (useSyncExternalStore) + التاريخ + التنبيهات
│   ├── editorActions.js كل عمليات التعديل (لضمان توافق التراجع)
│   ├── model.js       نموذج المشروع/المقطع/المسار + دوال مساعدة نقية
│   ├── media.js       سجل الوسائط + الاستيراد + توليد الأصول + الحفظ
│   ├── idb.js         غلاف IndexedDB
│   └── demo.js        بناء المشروع التجريبي الجاهز
├── components/
│   ├── ui.jsx         مكوّنات مشتركة (أيقونات، نوافذ، حقول، تنبيهات)
│   ├── Dashboard.jsx  الصفحة الرئيسية (المشاريع + المزايا + الأسئلة الشائعة)
│   └── editor/        الهيكل، الشريط العلوي، المعاينة، الخط الزمني، واللوحات
├── i18n/              القواميس العربية/الإنجليزية + أدوات التنسيق
├── styles/global.css  نظام التصميم الكامل (داكن، RTL/LTR)
└── acode-entry.jsx    نقطة دخول النسخة المستقلة (ملف HTML واحد)

scripts/build-acode.mjs  يبني acode/index.html + acode/dev.html (ملف واحد بدون شبكة)
acode/                   النسخة الجاهزة للموبايل (Acode) + دليل التشغيل
test/                    اختبارات المنطق و DOM و محاكاة WebView
```

**كيف يعمل التشغيل؟** ساعة `AudioContext` هي المرجع الزمني (مثل برامج المونتاج الحقيقية)،
وعناصر الفيديو تُصحَّح تلقائيًا عند الانحراف، ثم يُكوَّن كل إطار على الـ Canvas
(طبقات + فلاتر + انتقالات + نصوص + كابشن) ويُعرض فوريًا.

معالجة المشاريع المحفوظة، دوال الفلاتر، Keyframes، كشف الصمت والإيقاع (المعطيات)، توزيع الكابشن،
فهم المساعد للعربية والإنجليزية، تصدير واستيراد SRT، توليد العناوين، تطابق قواميس الترجمة، وتركيب التطبيق فعليًا في DOM.

## ملاحظات وحدود المتصفح

- **التصدير في الوقت الحقيقي:** مدة التصدير = مدة المشروع (بدون سيرفر). الصوت في تصدير الفيديو يُسجَّل من مخرج الصوت
  الداخلي، لذا يمكن كتم صوت النظام أثناء التصدير من لوحة التصدير.
- **صيغة الفيديو المُصدَّر:** WebM (VP9/VP8 + Opus) — مدعوم في يوتيوب والمتصفحات، ويمكن تحويله إلى MP4 بأي أداة.
- **الكابشن:** التفريغ المباشر يستخدم التعرف على الكلام المدمج في المتصفح من المايكروفون (Chrome)،
  أو توزيع نص السكربت على الكلام المكتشف زمنيًا — لا يوجد تفريغ سحابي.
- **مقاطع الـ MOV/HEVC أو الصيغ غير المدعومة في المتصفح** قد لا تُشغَّل — جرّب تحويلها إلى MP4/H.264.
- الملفات الكبيرة جدًا (فيديوهات طويلة) تُستهلك منها الذاكرة أثناء التحليل الصوتي؛ ابدأ بالمقاطع الأقصر.
